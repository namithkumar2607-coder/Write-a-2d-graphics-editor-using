Then, write three functions: one to add objects to the picture, one to delete objects from the picture, and one to modify objects already in the picture
7.Finally, tie it all together with an interactive text menu. The program should run in a loop, asking the user what they want to do: Add, Delete, Modify, or Display the picture.
